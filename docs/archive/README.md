# Archive

History moved out of the live documents so they stay short enough to read. Nothing here is current; everything here
was true when it was written. Search it before trying something that sounds new.

- **Session log:** `docs/SESSION-LOG.md` is already the history file (D-058). When it grows unwieldy, move the oldest
  sessions whole (do not summarise them) to `SESSION_LOG_YYYY_MM.md` here, and leave a one-line pointer
  ("Sessions 1 to 24: `docs/archive/SESSION_LOG_2026_09.md`"). `tools/check_docs.py` reads these files so session
  numbers stay unique.
- **Roadmap phases:** a finished phase can move to `ROADMAP_YYYY_MM.md`, items unchanged. Its IDs stay reserved.
- **Anything else** (an old handoff section, a retired document): one file per thing, with a line at the top saying
  when and why it was moved.

Archive content is historical, not normative. Never store secrets or real scripts here because they are old.
