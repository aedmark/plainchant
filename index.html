The premise

Writing software should help you write.

Margins, indentation, page breaks, file formats—Plainchant handles the machinery while you stay with the scene.

It reads lightweight Fountain text and formats it live. There is nothing proprietary between you and your work, and nothing to configure before “FADE IN.”

Start writing

Four steps.
That’s the whole primer.

Plainchant understands the shape of a script from the shape of your text. Use Tab to cycle an element when you want a hand; smart Enter takes it from there.

  1. 01

    Set the scene

    INT. ARCADE - NIGHT

    Start with INT. or EXT. and Plainchant recognises a scene heading.

  2. 02

    Call your character

    MARA

    Put a name in capitals. Names you have used before are suggested as you type.

  3. 03

    Let them speak

    One more life.

    Press Enter after a character and dialogue begins. Parentheticals work naturally too.

  4. 04

    Take it with you

    EXPORT → .FOUNTAIN / .FDX / PDF

    Print, save a PDF, or export for Fountain and Final Draft when the story is ready.

!

Stuck? Tap the element bar—Scene, Action, Character, Dialogue—or press Tab. Plainchant never makes you memorise syntax.
